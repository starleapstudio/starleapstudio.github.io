功能

从发现、创作到桌面渲染，完整闭环

对齐客户端「发现 / 已安装 / 创作坊」产品能力，以及 CloverScene 渲染与 `.cwp` 分发链路。

  1. 发现壁纸

    按全部、最新、风景、美女、治愈、游戏、萌宠、综合等分类浏览；支持排序、详情预览与订阅下载。

  2. 已安装与播放列表

    管理本地壁纸库，调节 FPS / 音量等属性；底部播放栏控制当前壁纸，支持播放列表与多显示器输出。

  3. 创作坊 · 场景编辑器

    Clover Editor 贴近 Wallpaper Engine 操作习惯：图层、视口、特效链与实时预览，支持图像 / 文字 / 粒子对象。

  4. CloverScene 渲染管线

    自研场景渲染，支持 Scroll / Shake / WaterWaves 等着色器特效、遮罩与粒子系统，流畅驱动桌面级动态壁纸。

  5. 视频与音频可视化

    视频壁纸经 MPV 渲染；可导入本地视频，或绑定系统音频生成频谱动效，让壁纸跟随音乐律动。

  6. .cwp 自包含分发

    Clover Wallpaper Package 将场景 / 视频 / 预览打包为单一文件，零外部依赖；兼容创作平台加密分发与本地导入。
